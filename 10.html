Backtracking#

The backtracking algorithm is typically used for the following problems: “Generate/Return all possible x (permutation/combination)”

Permutations#

This is the standard backtracking algorithm that will generate all permutations (order matters) of a certain size k and with repeating elements:

 1def permutations(self, nums):
 2    output = []
 3    def backtrack(sol=[]):
 4        //check if solution is valid, then add to solutions
 5        if len(sol) == k:
 6            output.append(sol[:])
 7            return
 8        for i in range(len(nums)):
 9            sol.append(nums[i])
10            backtrack(sol)
11            sol.pop()

  • The core of this algorithm is appending an element, then calling backtrack, and finally popping the element

    • This enables backtrack to generate different combinations and explore a possible solution

For generating all permutations of a certain size k (without repeating elements):

 1def permute(self, nums: List[int]) -> List[List[int]]:
 2        output = []
 3        def backtrack(sol=[]):
 4            if len(sol) == len(nums):
 5                output.append(sol[:])
 6                return
 7            for i in range(len(nums)):
 8                if nums[i] not in sol:
 9                    sol.append(nums[i])
10                    backtrack(sol)
11                    sol.pop()
12        backtrack()
13        return output

Combinations#

For generating combinations (order doesn’t matter)

 1def combinations(self, nums):
 2    output = []
 3    def backtrack(first=0, sol=[]):
 4        //check if solution is valid, then add to solutions
 5        if len(sol) == k:
 6            output.append(sol[:])
 7            return
 8        for i in range(first, len(nums)):
 9            sol.append(nums[i])
10            backtrack(i, sol) //backtrack(i + 1, sol) if you cannot use the same element more than once
11            sol.pop()

  • This avoids repeats because we are no longer able to use an element that we have used already with i + 1

If you must generate combinations that avoid duplicate solutions (because of repeating elements in the set),

 1def combinations(self, nums):
 2    output = []
 3    //sort to put duplicates together
 4    nums.sort()
 5    def backtrack(first=0, sol=[]):
 6        //check if solution is valid, then add to solutions
 7        if len(sol) == k:
 8            output.append(sol[:])
 9            return
10        for i in range(first, len(nums)):
11            //if avoiding duplicate solutions due to repeating elements 
12            if i != first and nums[i] == nums[i - 1]:
13                continue
14            sol.append(nums[i])
15            backtrack(i + 1, sol)
16            sol.pop()

  • Sorting will place all duplicate elements in the possible set together

  • The for loop will avoid duplicate solutions by avoiding duplicate elements

If you must generate combinations of varying lengths,

Path-finding in a Graph#

Backtracking can also be used to find all possible paths in a graph (or matrix) that satisfy some constraint(s)

  • Typically, you can add the node to the candidate, then backtrack into the node, then pop the node from the candidate

  • The candidate can be the path or even a visited set

For example, finding whether a word exists in a matrix:

 1def exist(self, board: List[List[str]], word: str) -> bool:
 2        def backtrack(r, c, word, visited):
 3            if word == "":
 4                return True
 5            directions = [(1, 0), (0, 1), (-1, 0), (0, -1)]
 6            for r_diff, c_diff in directions:
 7                new_row = r + r_diff
 8                new_col = c + c_diff
 9                if 0 <= new_row < m and 0 <= new_col < n and (new_row, new_col) not in visited and word[0] == board[new_row][new_col]:
10                    visited.add((new_row, new_col))
11                    if backtrack(new_row, new_col, word[1:], visited):
12                        return True
13                    visited.remove((new_row, new_col))
14            return False
15
16        m, n = len(board), len(board[0])
17        for r in range(m):
18            for c in range(n):
19                if board[r][c] == word[0]:
20                    visited = set([(r, c)])
21                    if backtrack(r, c, word[1:], visited):
22                        return True
23        return False

  • Only call backtrack if the solution is valid; this is why there is an if condition

  • Backtracking essentially explores a possible solution until it is completely valid, then the solution is appended to the output
