# Advanced Algorithms

These techniques are uncommon in typical coding interviews. This chapter gives a brief overview of the problems they solve.

## Binary Lifting

Binary lifting answers repeated **lowest common ancestor (LCA)** queries on a rooted tree. The LCA of two nodes is the deepest ancestor they share.

Precompute each node's ancestors at distances of `1, 2, 4, 8, ...` edges. The `2^j`-th ancestor comes from taking two jumps of size `2^(j - 1)`. To find the LCA, first lift the deeper node to the same depth as the other. If the nodes now match, that node is the LCA. Otherwise, try jumps from largest to smallest, moving both nodes up whenever their jump destinations differ. Their shared parent is the LCA.

Preprocessing takes `O(N log N)` time and space for a tree with `N` nodes. Each LCA query takes `O(log N)` time.

The path between `u` and `v` goes through their LCA. If `depth[x]` counts edges from the root to `x`, their distance is:

```text
distance(u, v) = depth[u] + depth[v] - 2 * depth[lca(u, v)]
```

For a weighted tree, use cumulative edge weights from the root in the distance formula and keep using edge counts to align depths during the LCA query. Either distance query takes `O(log N)` time.
