Dictionaries and Heaps#

Dictionaries#

A dictionary is a hash table that stores key-value pairs. Keys must be hashable. Dictionaries preserve insertion order, but lookup logic should normally depend on keys rather than their position.

The following example shows the recommended ways to access and remove keys:

 1data = {}
 2
 3data["Boba"] = "Tea"
 4
 5tea = data["Boba"]              # Strict lookup: raises KeyError if absent.
 6coffee = data.get("Coffee")     # Safe lookup: returns None if absent.
 7coffee = data.get("Coffee", 0)  # Or return a chosen default.
 8
 9if "Boba" in data:
10    print(data["Boba"])
11
12for key, value in data.items():
13    print(key, value)
14
15keys = list(data)            # Same keys as list(data.keys()).
16values = list(data.values())
17
18removed = data.pop("Boba", None)  # Remove safely and return the value.

Use mapping[key] when a missing key should be an error. Use mapping.get(key, default) when absence is expected. Do not combine them with mapping[key] or mapping.get(key): the strict lookup can raise first, and valid falsey values such as 0 would be handled incorrectly.

del mapping[key] and mapping.pop(key) both raise KeyError when the key is absent. Supplying a default to pop, as in mapping.pop(key, None), avoids that exception.

Avoid naming a variable dict, because that shadows Python’s built-in dict() constructor.

How is a Dictionary Typically Implemented?#

Python dictionaries use a hash table. Python computes hash(key), maps it into an internal table, and resolves collisions when different keys map to the same location. The exact layout is an implementation detail; CPython uses an open-addressed table rather than a linked list for every bucket.

Lookup, insertion, and deletion are O(1) on average and O(n) in the worst case. Resizing the table occasionally costs O(n), but insertion remains amortized O(1).

Types of Dictionaries#

The collections module provides useful dictionary-like types.

1from collections import defaultdict
2
3counts = defaultdict(int)  # Missing values begin at 0.
4groups = defaultdict(list) # Missing values begin as a new list.
5
6counts["a"] += 1
7groups["fruit"].append("apple")

Accessing a missing key with mapping[key] on a defaultdict creates and stores its default value. Use a normal dictionary with .get() when a lookup should not mutate the mapping.

1from collections import Counter
2
3counts = Counter(["a", "a", "b", "b", "c", "c"])
4print(counts["missing"])       # 0
5print(counts.most_common(2))  # [('a', 2), ('b', 2)]
6print(counts.total())         # 6

Counter(iterable) counts items automatically, returns zero for missing items, and provides helpers such as most_common(n) and total().

Heaps (Priority Queues)#

Heaps are useful for repeatedly accessing and removing the smallest item. Python’s heapq module implements a min-heap using a regular list.

 1import heapq
 2
 3heap = [5, 1, 4]
 4heapq.heapify(heap)  # Mutates the list into a heap in O(n).
 5
 6heapq.heappush(heap, 2)
 7smallest = heap[0]          # Peek without removing: 1
 8smallest = heapq.heappop(heap)  # Remove and return: 1
 9
10# Push first, then pop and return the smallest item.
11removed = heapq.heappushpop(heap, 3)
12
13# Return new lists without modifying heap.
14largest_two = heapq.nlargest(2, heap)
15smallest_two = heapq.nsmallest(2, heap)

For a max-heap of numeric priorities, negate values when pushing and negate them again when popping:

import heapq

max_heap = []
value = 10
heapq.heappush(max_heap, -value)
largest = -heapq.heappop(max_heap)

For items with a priority, push tuples such as (priority, value). Python compares tuple fields from left to right. If equal priorities may pair with values that cannot be compared, add a unique counter as the second tuple field.

heappushpop(heap, item) pushes and then pops efficiently. heapreplace(heap, item) pops first and then pushes, so it requires a non-empty heap and may return an item larger than the new one.
