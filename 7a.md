# Using BFS and DFS in a Matrix (Graph)
A matrix can be represented as a graph, where each cell typically has four neighbors: top, bottom, left, and right adjacent cells.

There are a lot of interesting problems utilizing a matrix that can be solved by using BFS or DFS. 

## BFS
Recall that BFS stands for Breadth First Search and explores level-by-level outward. 

Given a matrix `board`, where you want to execute BFS from specific nodes, (row, col), in order to accomplish some tasks like so:
- Fill nodes with closest distance to specific nodes
- Simulating disease spread
- Finding the closest exit

- For closest distance, you will iterate some `distance` variable by 1 per level

## DFS
Recall that DFS stands for Depth First Search and explores as deep as possible before backtracking.

DFS is typically used instead of BFS when trying to find specific nodes that satisfy some condition without needing to go level by level.
- If you don't need to use BFS, then just use DFS.

Here is the following skeleton code to accomplish DFS:
```{code-block} python
---
linenos:
---
def DFS(r, c):
    visited.add((r, c))
    //if board[r][c] met some condition(s), return it or add to array
    directions = [(1, 0), (0, 1), (-1, 0), (0, -1)]
    for row_diff, col_diff in directions:
        new_row = r + row_diff
        new_col = c + col_diff
        if 0 <= new_row < len(board) and 0 <= new_col < len(board[0]) and (new_row, new_col) not in visited:
            dfs(new_row, new_col)

for r in range(m):
    for c in range(n):
        if board[r][c] == <x>:
            DFS(r, c)

```

### DFS with Backtracking

Ordinary graph DFS usually marks a node as visited permanently because the goal is to process each node once. Backtracking is different: a cell is marked only while it belongs to the **current candidate path**, then unmarked when that path finishes. This lets another candidate path reuse the cell later.

The pattern is:

1. **Choose:** mark the current cell as part of the path.
2. **Explore:** recursively try every valid next cell.
3. **Unchoose:** restore the current cell before returning.

For example, determine whether a word can be formed from horizontally or vertically adjacent cells. A cell may be used at most once within the same path:

```{code-block} python
---
linenos:
---
def word_exists(board, word):
    if not word:
        return True
    if not board or not board[0]:
        return False

    rows, cols = len(board), len(board[0])
    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    def dfs(row, col, index):
        if not (0 <= row < rows and 0 <= col < cols):
            return False
        if board[row][col] != word[index]:
            return False
        if index == len(word) - 1:
            return True

        value = board[row][col]
        board[row][col] = None  # Choose: mark this cell as used.

        found = any(
            dfs(row + dr, col + dc, index + 1)
            for dr, dc in directions
        )

        board[row][col] = value  # Unchoose: restore for other paths.
        return found

    for row in range(rows):
        for col in range(cols):
            if dfs(row, col, 0):
                return True

    return False
```

The temporary `None` acts like a path-local visited set. Restoring the original value is essential—even when one recursive branch succeeds—because callers generally expect `board` to remain unchanged.

If the word length is `L`, the worst-case time is `O(RC · 4^L)` for an `R × C` board, and the recursion stack uses `O(L)` space. Backtracking is appropriate when the problem asks whether a path exists, to return one valid path, or to enumerate paths under constraints.
