# Using BFS and DFS in a Matrix (Graph)
A matrix can be represented as a graph, where each cell typically has four neighbors: top, bottom, left, and right adjacent cells.

There are a lot of interesting problems utilizing a matrix that can be solved by using BFS or DFS. 

## BFS
Recall that BFS stands for Breadth First Search and explores level-by-level outward. 

Given a matrix `board`, where you want to execute BFS from specific nodes, (row, col), in order to accomplish some tasks like so:
- Fill nodes with closest distance to specific nodes
- Simulating disease spread
- Finding the closest exit

Here is the following skeleton code to accomplish BFS:
```{code-block} python

visited = set()
for r in range(m):
```

For the different tasks, you will typically keep track of some variables in the process of the BFS:
- For closest distance, you will iterate some `distance` variable by 1 per level
- For simulating disease spread, you will probably need a `time` variable to keep track of time passed (e.g. 1 min/level). 

## DFS
Recall that DFS stands for Depth First Search and explores as deep as possible before backtracking.

DFS is typically used instead of BFS when trying to find specific nodes that satisfy some condition without needing to go level by level.
- If you don't need to use BFS, then just use DFS.

Here is the following skeleton code to accomplish DFS:
```{code-block} python
---
linenos:
---
def DFS(r, c):
    visited.add((r, c))
    //if board[r][c] met some condition(s), return it or add to array
    directions = [(1, 0), (0, 1), (-1, 0), (0, -1)]
    for row_diff, col_diff in directions:
        new_row = r + row_diff
        new_col = c + col_diff
        if 0 <= new_row < len(board) and 0 <= new_col < len(board[0]) and (new_row, new_col) not in visited:
            dfs(new_row, new_col)

for r in range(m):
    for c in range(n):
        if board[r][c] == <x>:
            DFS(r, c)

```

### DFS with Backtracking

Ordinary graph DFS usually marks a node as visited permanently because the goal is to process each node once. Backtracking is different: a cell is marked only while it belongs to the **current candidate path**, then unmarked when that path finishes. This lets another candidate path reuse the cell later.

The pattern is:

1. **Choose:** mark the current cell as part of the path.
2. **Explore:** recursively try every valid next cell.
3. **Unchoose:** restore the current cell before returning.

For example, determine whether a word can be formed from horizontally or vertically adjacent cells. A cell may be used at most once within the same path:

```{code-block} python
---
linenos:
---
def word_exists(board, word):
    if not word:
        return True
    if not board or not board[0]:
        return False

    rows, cols = len(board), len(board[0])
    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    def dfs(row, col, index):
        if not (0 <= row < rows and 0 <= col < cols):
            return False
        if board[row][col] != word[index]:
            return False
        if index == len(word) - 1:
            return True

        value = board[row][col]
        board[row][col] = None  # Choose: mark this cell as used.

        found = any(
            dfs(row + dr, col + dc, index + 1)
            for dr, dc in directions
        )

        board[row][col] = value  # Unchoose: restore for other paths.
        return found

    for row in range(rows):
        for col in range(cols):
            if dfs(row, col, 0):
                return True

    return False
```

The temporary `None` acts like a path-local visited set. Restoring the original value is essential—even when one recursive branch succeeds—because callers generally expect `board` to remain unchanged.

If the word length is `L`, the worst-case time is `O(RC · 4^L)` for an `R × C` board, and the recursion stack uses `O(L)` space. Backtracking is appropriate when the problem asks whether a path exists, to return one valid path, or to enumerate paths under constraints.

### Cycle Detection and Bridges with Discovery Rank

In an undirected graph, a **bridge** is an edge whose removal increases the number of connected components. An edge on a cycle always has an alternate route between its endpoints. To find bridges, use DFS to mark every edge on a cycle and remove those edges from the list of bridge candidates.

When to use it

- Detect cycles in an undirected graph by looking for a back edge from a node to an ancestor in the DFS tree.
- Find single points of failure in a network, such as the critical connections that would disconnect parts of the network if removed.
- To make the graph acyclic while preserving connectivity within each component, keep the DFS tree edges and remove the back edges. Removing every edge on a cycle can disconnect the graph.

Give each node a **discovery rank** when DFS first visits it. A call to `dfs(node, parent_edge)` returns the smallest rank reachable from the node's DFS subtree by following tree edges downward and using at most one back edge. This is called its **low-link value**.

- A back edge goes to an ancestor and closes a cycle. Mark the edge and use the ancestor's discovery rank to update the low-link value.
- A tree edge from `node` to `child` is on a cycle if `child_low <= rank[node]`. The child's subtree can reach `node` or an ancestor without using that tree edge. If `child_low > rank[node]`, the tree edge is a bridge.

In **Critical Connections in a Network**, return the edges that remain after filtering out the cycle edges. Give each edge an ID so DFS skips exactly the edge it arrived on, which also handles parallel edges.

```{code-block} python
---
linenos:
---
class Solution:
    def criticalConnections(
        self, n: int, connections: list[list[int]]
    ) -> list[list[int]]:
        adj = [[] for _ in range(n)]
        for edge_id, (u, v) in enumerate(connections):
            adj[u].append((v, edge_id))
            adj[v].append((u, edge_id))

        rank = [-1] * n
        on_cycle = [False] * len(connections)
        next_rank = 0

        def dfs(node, parent_edge):
            nonlocal next_rank
            rank[node] = next_rank
            next_rank += 1
            low = rank[node]

            for neighbor, edge_id in adj[node]:
                if edge_id == parent_edge:
                    continue

                if rank[neighbor] == -1:
                    child_low = dfs(neighbor, edge_id)
                    if child_low <= rank[node]:
                        on_cycle[edge_id] = True
                    low = min(low, child_low)
                elif rank[neighbor] <= rank[node]:
                    # A back edge to an ancestor, or a self-loop.
                    on_cycle[edge_id] = True
                    low = min(low, rank[neighbor])

            return low

        for node in range(n):
            if rank[node] == -1:
                dfs(node, -1)

        return [
            [u, v]
            for edge_id, (u, v) in enumerate(connections)
            if not on_cycle[edge_id]
        ]
```

For `connections = [[0, 1], [1, 2], [2, 0], [1, 3]]`, the triangle edges are on a cycle and the result is `[[1, 3]]`.

- **Time** is `O(V + E)) because DFS examines each undirected edge from both endpoints.
- **Auxiliary space** is `O(V + E)) for the adjacency list, arrays, and recursion stack. For graphs with very deep DFS trees, use an explicit stack to avoid Python's recursion limit.
