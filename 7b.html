Topological Sorting and Union Find#

Both topological sorting and union find are algorithms/strategies for solving some graph problems.

Topological Sorting#

Topological Sorting is the process of sorting the vertices in a graph such that given vertices u and v, to reach vertex v, we must have reached vertex u. Therefore, u has to appear before v in the ordering given by topological sorting.

  • This will only work with DAG (Directed, Acyclic Graph)

  • Can detect a cycle in a directed graph if the algorithm doesn’t order ALL nodes in the graph.

Here is the code for topological sort.

  • Note: indegree refers to the number of edges pointing into some node.

 1def topo_sort(edges):
 2    node_indegree = defaultdict(int)
 3    neighbors = defaultdict(list)
 4    q = deque()
 5    for x, y in edges:
 6        node_indegree[y] += 1
 7        neighbors[x].append(y)
 8    for node, indegree in node_indegree.items():
 9        if indegree == 0:
10            q.append(node)
11    ordering = []
12    while q:
13        node = q.popleft()
14        ordering.append(node)
15        for nei in neighbors[node]:
16            node_indegree[nei] -= 1
17            if node_indegree[nei] == 0:
18                q.append(node)
19    return ordering

The code accomplishes the following steps in order:

  • Store the indegree and the neighbors of each node

  • Append all nodes with indegree 0 to the queue

  • While the q exists:

    • Pop node from the queue, and decrement the indegree of its neighbors

    • If the indegree becomes 0, then append to the queue

Longest Path in a DAG: Topological Sort + DP#

Finding a longest path is difficult in a general graph because the graph may contain cycles. In a DAG, however, topological sorting processes each node only after all of its incoming dependencies have been processed. This lets us combine Kahn’s algorithm with dynamic programming.

Let dp[v] be the maximum number of edges in any path ending at node v. Every node starts with a path length of 0. When processing an edge from u to v, update:

dp[v] = max(dp[v], dp[u] + 1)

The longest path in the entire DAG is the largest value in dp:

 1from collections import deque
 2
 3
 4def longest_path_length(num_nodes, edges):
 5    adj = [[] for _ in range(num_nodes)]
 6    indegree = [0] * num_nodes
 7
 8    for u, v in edges:
 9        adj[u].append(v)
10        indegree[v] += 1
11
12    queue = deque(node for node in range(num_nodes) if indegree[node] == 0)
13    dp = [0] * num_nodes
14    processed = 0
15
16    while queue:
17        u = queue.popleft()
18        processed += 1
19
20        for v in adj[u]:
21            dp[v] = max(dp[v], dp[u] + 1)
22
23            indegree[v] -= 1
24            if indegree[v] == 0:
25                queue.append(v)
26
27    if processed != num_nodes:
28        raise ValueError("The graph must be a DAG")
29
30    return max(dp, default=0)
31
32
33edges = [
34    (0, 1),
35    (0, 2),
36    (1, 2),
37    (1, 3),
38    (2, 3),
39    (2, 4),
40    (3, 5),
41    (4, 5),
42]
43
44print(longest_path_length(6, edges))  # 4

The nodes are processed in topological order as they are removed from the queue, so a separate topological ordering does not need to be stored. If the graph contains a cycle, some nodes never reach an indegree of 0; the processed check detects this.

Reconstructing the Longest Path#

Finding the length does not require storing the actual path. If the path is also needed, keep track of the parent that produced each node’s best dp value:

 1from collections import deque
 2
 3
 4def longest_path(num_nodes, edges):
 5    adj = [[] for _ in range(num_nodes)]
 6    indegree = [0] * num_nodes
 7
 8    for u, v in edges:
 9        adj[u].append(v)
10        indegree[v] += 1
11
12    queue = deque(node for node in range(num_nodes) if indegree[node] == 0)
13    dp = [0] * num_nodes
14    parent = [-1] * num_nodes
15    processed = 0
16
17    while queue:
18        u = queue.popleft()
19        processed += 1
20
21        for v in adj[u]:
22            if dp[u] + 1 > dp[v]:
23                dp[v] = dp[u] + 1
24                parent[v] = u
25
26            indegree[v] -= 1
27            if indegree[v] == 0:
28                queue.append(v)
29
30    if processed != num_nodes:
31        raise ValueError("The graph must be a DAG")
32
33    if num_nodes == 0:
34        return []
35
36    end = max(range(num_nodes), key=lambda node: dp[node])
37    path = []
38
39    while end != -1:
40        path.append(end)
41        end = parent[end]
42
43    return path[::-1]
44
45
46print(longest_path(6, edges))  # [0, 1, 2, 3, 5]

When multiple longest paths exist, this returns one of them.

Both versions take O(V + E) time and use O(V + E) space.

Union Find#

A union find is a data structure that keeps track of elements (nodes) which are split into one or more disjoint sets (connected components) It has two primary operations: find and union:

  • find(x) returns the root (representative) of the set containing x and compresses the path from x to that root.

  • union(x, y) merges the two sets by attaching the lower-rank root below the higher-rank root.

Using path compression and union by rank together gives O(α(N)) amortized time per operation, where α is the inverse Ackermann function and grows so slowly that the operations are effectively constant time.

Here is the code for the Union Find (DSU) data structure:

 1class DSU:
 2    def __init__(self, size):
 3        self.parent = list(range(size))
 4        self.rank = [0] * size
 5
 6    def find(self, x):
 7        if self.parent[x] != x:
 8            self.parent[x] = self.find(self.parent[x])
 9        return self.parent[x]
10
11    def union(self, x, y):
12        root_x = self.find(x)
13        root_y = self.find(y)
14
15        if root_x == root_y:
16            return False
17
18        if self.rank[root_x] < self.rank[root_y]:
19            self.parent[root_x] = root_y
20        elif self.rank[root_x] > self.rank[root_y]:
21            self.parent[root_y] = root_x
22        else:
23            self.parent[root_y] = root_x
24            self.rank[root_x] += 1
25
26        return True

Walking through each method:

  • parent[x] points to the next node toward the root. Initially every node is its own root.

  • rank[root] is an upper bound on the tree’s height. It is meaningful only for roots.

  • find(x) performs path compression by making every node on the search path point directly to the root.

  • union(x, y) attaches the lower-rank root to the higher-rank root, keeping the tree shallow.

  • When both roots have the same rank, either may become the parent; its rank increases by 1 because the merged tree is one level taller.

  • union returns False when x and y are already connected. This is useful for detecting a redundant edge or cycle.

Rank should not increase on every union. It increases only when two roots with equal rank are combined. Path compression may later shorten the tree, but the stored rank does not need to be reduced.

Union Find is useful in many different applications:

  • Finding which edge(s) create cycles

  • Connected Components

  • Kruskal’s Minimum Spanning Tree algorithm

  • Tree Validation
