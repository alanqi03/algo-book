# Minimum Spanning Trees

A **minimum spanning tree (MST)** connects every vertex in a weighted, undirected graph with the smallest possible total edge weight.

A spanning tree:

- Includes every vertex
- Has no cycles
- Has exactly `V - 1` edges

An MST exists only if the graph is connected. It may not be unique when multiple edges have the same weight.

The two common greedy algorithms are:

| Algorithm | Main idea | Typical input | Time |
|---|---|---|---|
| Prim's with a heap | Grow one tree using its cheapest outgoing edge | Sparse adjacency list | `O(E log V)` |
| Prim's with a linear scan | Grow one tree using its cheapest outgoing edge | Dense adjacency matrix | `O(V²)` |
| Kruskal's | Add the cheapest edge that does not create a cycle | Edge list | `O(E log E)` |

## Prim's Algorithm

Prim's algorithm starts at any vertex and grows one connected tree by repeatedly adding its cheapest outgoing edge.

### Heap Implementation

A min-heap efficiently stores candidate edges that connect the current tree to another vertex.

1. Push a zero-cost edge to any starting vertex.
2. Pop the cheapest edge.
3. If its destination is already in the MST, skip it.
4. Otherwise, add its cost and push its outgoing edges.
5. Continue until all vertices are included.

```{code-block} python
---
linenos:
---
import heapq

def prim(n, graph):
    """graph[u] contains (weight, v) pairs; vertices are 0 through n - 1."""
    if n == 0:
        return 0

    total_cost = 0
    vertices_used = 0
    in_mst = [False] * n
    heap = [(0, 0)]  # (edge weight, destination)

    while heap and vertices_used < n:
        weight, u = heapq.heappop(heap)

        if in_mst[u]:
            continue

        in_mst[u] = True
        total_cost += weight
        vertices_used += 1

        for next_weight, v in graph[u]:
            if not in_mst[v]:
                heapq.heappush(heap, (next_weight, v))

    return total_cost if vertices_used == n else -1
```

Returning `-1` means the graph is disconnected, so one spanning tree cannot reach every vertex.

### Linear-Scan Implementation

The `O(V²)` version keeps two pieces of information for each vertex:

- `in_mst[v]`: whether vertex `v` has already been added
- `cheapest_connection[v]`: the cheapest known edge from the current MST to `v`

Each outer-loop iteration adds exactly one vertex:

1. Scan all vertices to find the unvisited vertex with the cheapest connection.
2. Add that vertex and its connection cost to the MST.
3. Scan its edges to see whether it offers a cheaper connection to any unvisited vertex.

```{code-block} python
---
linenos:
---
def prim_dense(matrix):
    """matrix[u][v] is the edge weight, or infinity if no edge exists."""
    n = len(matrix)
    if n == 0:
        return 0

    in_mst = [False] * n
    cheapest_connection = [float("inf")] * n
    cheapest_connection[0] = 0  # Start at vertex 0 for free.
    total_cost = 0

    for _ in range(n):
        # 1. Find the cheapest vertex that is not in the MST.
        next_vertex = -1
        for candidate in range(n):
            if in_mst[candidate]:
                continue
            if (
                next_vertex == -1
                or cheapest_connection[candidate]
                < cheapest_connection[next_vertex]
            ):
                next_vertex = candidate

        # No edge can connect the remaining vertices.
        if (
            next_vertex == -1
            or cheapest_connection[next_vertex] == float("inf")
        ):
            return -1

        # 2. Add that vertex using its cheapest connection.
        in_mst[next_vertex] = True
        total_cost += cheapest_connection[next_vertex]

        # 3. Update the cheapest connection to each remaining vertex.
        for neighbor in range(n):
            if not in_mst[neighbor]:
                cheapest_connection[neighbor] = min(
                    cheapest_connection[neighbor],
                    matrix[next_vertex][neighbor],
                )

    return total_cost
```

The first scan answers, “Which vertex is cheapest to add next?” The second scan answers, “Now that this vertex is in the tree, does it give us a cheaper way to add any others?”

The outer loop runs `V` times, and both inner scans examine at most `V` vertices. Therefore, the total time is `O(V²)`.

For example, if adding vertex `2` reveals an edge of weight `4` to vertex `3`, but the best known connection to vertex `3` was `7`, update it to `4`.

This version also works well for an **implicit** graph. For example, when every pair of points is connected, calculate the distance between `next_vertex` and `neighbor` inside the final loop instead of building an `O(V²)` matrix.

## Kruskal's Algorithm

Kruskal's algorithm considers all edges from cheapest to most expensive. It uses a Disjoint Set Union (DSU) to check whether two vertices are already connected.

1. Sort all edges by weight.
2. Add an edge if it connects two different components.
3. Stop after choosing `V - 1` edges.

```{code-block} python
---
linenos:
---
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        if x != self.parent[x]:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        root_a = self.find(a)
        root_b = self.find(b)

        if root_a == root_b:
            return False

        if self.size[root_a] < self.size[root_b]:
            root_a, root_b = root_b, root_a

        self.parent[root_b] = root_a
        self.size[root_a] += self.size[root_b]
        return True


def kruskal(n, edges):
    """edges contains (weight, u, v) tuples; vertices are 0 through n - 1."""
    if n <= 1:
        return 0

    dsu = DSU(n)
    total_cost = 0
    edges_used = 0

    for weight, u, v in sorted(edges):
        if dsu.union(u, v):
            total_cost += weight
            edges_used += 1

            if edges_used == n - 1:
                return total_cost

    return -1
```

DSU's `find` operation identifies a vertex's component. If two vertices have the same root, adding their edge would create a cycle, so Kruskal skips it.
