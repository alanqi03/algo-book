# Heap
This section will go over problems that can be solved using the heap data structure. 

## `heapq` Library
The `heapq` library in Python will be very useful for solving these types of problems. 
Here are the most relevant methods:
- `heapq.heapify(var)` will transform an iterable variable `var` (e.g. []) into a **min** heap
- `heap[0]` will return the min value (root)
- `heapq.heappush(heap, val)` will push the `val` onto the `heap`
- `heapq.heappop(heap)` will pop the min root 
- `heapq.heappushpop(heap, val)` will push the `val` onto the `heap` and remove/return the min value at the root
- `heapq.nlargest(n, heap, key=None)` will return the n largest elements in the heap based on a key, if defined
- `heapq.nsmallest(n, heap, key=None)` will return the n smallest elements in the heap based on a key, if defined

You can transform this heap into a max heap if you multiple every val added by -1. 

## Big O Complexity of a Heap
O(logN) push, O(logN) pop, O(NlogN) push all elements

## General Tips
Here are some general tips for using heaps:
- For k largest/smallest element, in order to optimize, you can limit the size of the minHeap/maxHeap to k and the root will be the kth element. 
- If you store tuples in the heap, the heap will sort by first element in tuple and break ties with second element
    - Knowing this fact, you can compare the "value" by storing it as the first element in a tuple and a "key" or "id" as the second element in a tuple. 

## Quickselect

Quickselect finds the element that would appear at a particular index if an array were sorted, without sorting the entire array. It uses the same partition operation as Quicksort:

1. Choose a pivot.
2. Move values smaller than the pivot to its left and larger or equal values to its right.
3. The pivot is now at its final sorted index.
4. Continue only in the side containing the target index.

Quickselect is useful for finding a single kth smallest or kth largest element in an unsorted array. A randomized pivot gives `O(n)` expected time, although the worst case remains `O(n²)`.

### Kth Largest Element

The kth largest element has ascending sorted index `len(nums) - k`. For example, the second-largest value in a five-element array belongs at index `5 - 2 = 3`.

```{code-block} python

import random


def partition(nums, left, right, pivot_index):
    pivot = nums[pivot_index]
    nums[pivot_index], nums[right] = nums[right], nums[pivot_index]

    store_index = left
    for i in range(left, right):
        if nums[i] < pivot:
            nums[store_index], nums[i] = nums[i], nums[store_index]
            store_index += 1

    nums[store_index], nums[right] = nums[right], nums[store_index]
    return store_index


def kth_largest(nums, k):
    if not 1 <= k <= len(nums):
        raise ValueError("k must be between 1 and len(nums)")

    target = len(nums) - k
    left, right = 0, len(nums) - 1

    while left <= right:
        pivot_index = random.randint(left, right)
        pivot_index = partition(nums, left, right, pivot_index)

        if pivot_index == target:
            return nums[pivot_index]
        if pivot_index < target:
            left = pivot_index + 1
        else:
            right = pivot_index - 1
```

For `nums = [3, 2, 1, 5, 6, 4]` and `k = 2`, the target index is `4`, and the function returns `5`.

After each partition, the pivot is in its final position. Everything on one side can be discarded, so Quickselect does not recursively process both partitions like Quicksort. The input order is modified; call `kth_largest(nums[:], k)` if the original list must be preserved.

### Complexity

- **Expected time:** `O(n)`. Random pivots usually discard a substantial portion of the remaining search range.
- **Worst-case time:** `O(n²)`. This occurs if each pivot repeatedly leaves only one element outside the next search range.
- **Auxiliary space:** `O(1)` for this iterative, in-place implementation.

### Quickselect vs. a Heap

| Requirement | Prefer |
| --- | --- |
| One kth-element query on an array | Quickselect: `O(n)` expected time |
| Predictable worst-case behavior | Heap: `O(n log k)` time |
| Values arrive as a stream | Heap of size `k` |
| Need all top `k` values | Heap or sorting |
| Must preserve the input order without copying | Heap |
