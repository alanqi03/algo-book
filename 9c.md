# 2D DP
2D DP problems use two variables to describe each subproblem, stored in a 2D table `dp[i][j]`. The two most common flavors are **grid** problems (moving through a matrix) and **string** problems (comparing two strings or two ranges of one string).

## Grid DP
Here `dp[i][j]` is the answer for the cell at row `i`, column `j`, usually built from the cells above and to the left.

### When to use
1. You move through a 2D grid, typically only right and/or down.
2. You're asked for the number of paths, or the min/max cost path, to reach each cell.

### Algorithm
Counting unique paths from the top-left to the bottom-right, moving only right or down:
```{code-block} python
---
linenos:
---
def unique_paths(m, n):
    dp = [[1] * n for _ in range(m)]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
    return dp[m - 1][n - 1]
```
- `dp[i][j]` is the number of ways to reach cell `(i, j)`.
- Each cell is reached from directly above (`i-1, j`) or directly left (`i, j-1`).
- The first row and column are all `1`, since there is only one straight-line path to them.

## String DP
Here `dp[i][j]` describes a relationship between the first `i` characters of one string and the first `j` characters of another (or two indices into the same string).

### When to use
1. You're comparing two strings (edit distance, common subsequence) or two ends of one string (palindromes).
2. The answer for a pair of prefixes depends on smaller prefixes.

### Algorithm
Longest Common Subsequence (LCS) of strings `a` and `b`:
```{code-block} python
---
linenos:
---
def lcs(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```
- `dp[i][j]` is the LCS length using the first `i` characters of `a` and the first `j` of `b`.
- If the current characters match, extend the diagonal subproblem `dp[i-1][j-1]` by 1.
- Otherwise take the better of dropping a character from either string.

## Tips and tricks
- Adding an extra row and column of base cases (index `0` meaning "empty") avoids special-casing the boundaries.
- Since each cell usually depends only on the previous row, you can often reduce space to two rows (or one) — `O(n)` instead of `O(m*n)`.
- For string problems, be careful with off-by-one: `dp[i]` refers to the first `i` characters, so the character itself is at index `i-1`.
