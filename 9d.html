Complex DP#

Beyond the standard 1D, 2D, and knapsack patterns, some problems need a state that is shaped differently — a range, a subtree, a subset, or a position within a number. These are less common but follow the same core idea: define the state, write the recurrence, handle base cases.

Interval DP#

The state is a range dp[i][j] describing the subproblem on the interval from index i to j. You typically build up from smaller intervals to larger ones, often by choosing a “split point” k inside the range.

When to use#

  1. The answer for a range is built by combining answers of sub-ranges.

  2. You choose where to split, merge, or which element to handle last within an interval (e.g. matrix chain multiplication, bursting balloons).

Algorithm#

The general shape iterates intervals by increasing length:

1def interval_dp(n):
2    dp = [[0] * n for _ in range(n)]
3    for length in range(2, n + 1):          # interval length
4        for i in range(n - length + 1):     # left end
5            j = i + length - 1              # right end
6            dp[i][j] = float("inf")
7            for k in range(i, j):           # split point
8                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k + 1][j] + cost(i, k, j))
9    return dp[0][n - 1]

  • dp[i][j] is the best answer for the interval [i, j].

  • The outer loop grows the interval length so smaller intervals are solved first.

  • cost(i, k, j) is the problem-specific cost of combining the two halves.

Tree DP#

The state is defined per node, computed from its children via a post-order (bottom-up) traversal. Each node returns the answer for its own subtree.

When to use#

  1. The input is a tree and each node’s answer depends on its children’s answers.

  2. Classic examples: House Robber III, max path sum, and counting/coloring problems on trees.

Algorithm#

House Robber III — at each node, choose to rob it (and skip children) or skip it:

 1def rob(root):
 2    def dfs(node):
 3        if not node:
 4            return (0, 0)               # (rob this node, skip this node)
 5        l = dfs(node.left)
 6        r = dfs(node.right)
 7        rob_node = node.val + l[1] + r[1]
 8        skip_node = max(l) + max(r)
 9        return (rob_node, skip_node)
10    return max(dfs(root))

  • Each call returns two values: the best total if we rob this node, and if we skip it.

  • Robbing a node forces skipping its children; skipping lets each child choose freely.

  • The recursion is a postorder DFS — children are solved before the parent.

Bit DP (Bitmask DP)#

The state includes a bitmask representing a subset of elements, where bit i marks whether element i is included. Useful when n is small (roughly n <= 20) because there are 2^n subsets.

When to use#

  1. You must track which subset of a small set of items has been used or visited.

  2. Classic examples: Traveling Salesman, assignment problems, “count ways to fully cover” problems.

Algorithm#

The state is often dp[mask] (or dp[mask][i]), iterating over all masks:

1def bitmask_dp(n):
2    dp = [0] * (1 << n)                 # 2^n states
3    dp[0] = base_case
4    for mask in range(1 << n):
5        for i in range(n):
6            if not (mask & (1 << i)):    # element i not yet used
7                nxt = mask | (1 << i)    # add element i to the subset
8                dp[nxt] = combine(dp[nxt], dp[mask], i)
9    return dp[(1 << n) - 1]              # all elements used

  • mask is a subset of the n items; bit i set means item i is included.

  • mask & (1 << i) checks membership; mask | (1 << i) adds an item.

  • The full set is (1 << n) - 1 (all bits set).

Digit DP#

The state walks the digits of a number left to right, counting how many numbers up to some limit satisfy a property. The state usually tracks the digit position and whether the prefix is still “tight” (equal to the limit’s prefix).

When to use#

  1. You’re asked to count numbers in a range [0, N] (or [L, R]) with some digit property.

  2. N is far too large to iterate one number at a time, but has few digits.

Algorithm#

The typical recursion is over (position, tight, ...):

 1def digit_dp(N):
 2    digits = list(map(int, str(N)))
 3    from functools import lru_cache
 4
 5    @lru_cache(None)
 6    def dp(pos, tight):
 7        if pos == len(digits):
 8            return 1                     # one valid number formed
 9        limit = digits[pos] if tight else 9
10        total = 0
11        for d in range(0, limit + 1):
12            total += dp(pos + 1, tight and d == limit)
13        return total
14    return dp(0, True)

  • pos is the current digit index; tight means the prefix so far matches N’s prefix.

  • When tight, the current digit can go at most up to N’s digit; otherwise up to 9.

  • Add more state parameters (e.g. running sum, last digit) to encode the specific property being counted.

Tips and tricks#

  • These patterns are all “define the state, write the recurrence” — only the shape of the state changes (range, node, subset, digit position).

  • Reach for these only when the standard 1D/2D/knapsack states can’t capture the problem; they are less common in interviews.

  • Bitmask DP is only feasible for small n (about 20 or fewer) because of the 2^n states.
