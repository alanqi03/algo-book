# Math and Geometry
This section will go over common math and geometry problems.

## Math to Know
### Counting
These counting facts show up constantly, especially when reasoning about brute-force sizes and time complexity:
- There are $2^n$ **subsets** (or subsequences) of a set of $n$ elements — each element is either in or out. This is why generating all subsets is $O(2^n)$.
- There are $n!$ **permutations** (orderings) of $n$ distinct elements. Generating all permutations is $O(n!)$.
- There are $n(n-1)/2$ **pairs** of elements in a set of $n$, so a nested loop over all pairs is $O(n^2)$.
- There are $n - k + 1$ contiguous **subarrays (windows)** of length $k$ in an array of length $n$.

### Combinations
Number of combinations of different elements for different categories:
- $x * y * z * ...$ where x, y, z, ... are the number of different elements corresponding to unique categories.

Permutations: $\frac{n!}{(n - k)!}$ - strings of length k from alphabet of size n, where characters can not be repeated and order matters.

Combinations: (n choose k) = $\frac{n!}{((n - k)! * k!)}$ - form teams of size k from n people, where characters cannot be repeated and order doesn't matter.

### Elementary Operations
Both multiplication and addition utilize a `carry`, where if the addition of two numbers is greater than 9, $a + b > 9$, then the carry == 1; else, the carry == 0. 
- If the carry is 1, then you need to add it to the `i + 1` digit (place), given that `i` is the current digit (place) that you are summing. 

Addition over an array can be optimized using the Gauss' Summation:
$$1 + 2 + ... + n = \frac{n(n+1)}{2}$$
$$x + (x + 1) + ... + n = \frac{(x - n + 1)(x + n)}{2}$$

The power function is inherently recursive:
- If the power is even, then $2^x = 2 ^ {(x / 2)} * 2 ^ {(x / 2)}$
- If the power is odd, then $2^{(x + 1)} = 2 ^ {(x / 2)} * 2 ^ {(x / 2)} * 2$
- The base cases are the 0th power and the 1st power. 

### Working with Digits
To break an integer into its digits without converting to a string:
- `n % 10` gives the last (rightmost) digit.
- `n // 10` removes the last digit.
- Repeat until `n == 0` to process every digit from right to left.

Related facts:
- A number `n` has $\lfloor \log_{10}(n) \rfloor + 1$ digits (in base 10).
- Multiplying by 10 shifts digits left (appends a 0); dividing by 10 shifts right.

### Modular Arithmetic
The modulo operator (`%`) gives the remainder and is useful for wrapping and cycling:
- `i % n` keeps an index in the range `[0, n)`, which is handy for circular arrays.
- `n % 2` tests even (`0`) vs. odd (`1`).
- Modulo distributes over addition and multiplication, so large results can be kept small:
$$(a + b) \bmod m = ((a \bmod m) + (b \bmod m)) \bmod m$$
$$(a * b) \bmod m = ((a \bmod m) * (b \bmod m)) \bmod m$$
- Problems that ask for a huge count "modulo $10^9 + 7$" want you to apply the mod at each step to avoid overflow.

### Primes, GCD, and LCM
- A number is **prime** if it has no divisors other than 1 and itself. You only need to check divisors up to $\sqrt{n}$, since any factor larger than $\sqrt{n}$ pairs with one smaller than it.
- The **greatest common divisor (GCD)** is the largest number dividing two values; Python provides `math.gcd(a, b)`.
- The **least common multiple (LCM)** relates to the GCD by $\text{lcm}(a, b) = \frac{a * b}{\gcd(a, b)}$.
