# Basics, Functions, Numbers, and Strings

## Basics
### Iteration
The following code block is a for loop and a while loop:

```{code-block} python
---
linenos:
---
for i in range(50):
    print(i)

i = 0
while i < 50:
    print(i)
    i += 1
```

Executing `break` within a loop will exit the loop prematurely. 

Executing `continue` within a loop will skip any code and continue to the next iteration.  

### Conditionals
The following code block is an if-elif-else statement and a if-else one-line ternary operator:

```{code-block} python
---
linenos:
---
i = "alan"
if i == "alan":
    print("hey, that's me!")
elif i == "you":
    print("hey, that's you!")
else:
    print("Who else is reading this?")

message = "hey, that's me!" if i == "alan" else "hey, that's you, or is it?"
print(message)
```

Conditional expressions are best used to choose a value. A regular `if` statement is usually clearer when each branch performs an action.

## Functions
Here is an example function: 
```{code-block} python
---
linenos:
---
def my_function(me):
    print(me)
```

Python has many useful built-in functions. These are especially common in technical interviews:

| Function | What it does | Important behavior |
|---|---|---|
| `abs(x)` | Returns the absolute value of `x` | Works with numeric types that define absolute value |
| `all(iterable)` | Returns whether every item is truthy | Returns `True` for an empty iterable |
| `any(iterable)` | Returns whether at least one item is truthy | Returns `False` for an empty iterable |
| `bin(integer)` | Returns the binary representation | The result is a string beginning with `0b` |
| `bool(x)` | Converts `x` to `True` or `False` | Empty containers, zero, and `None` are falsey |
| `dict(...)` | Creates a dictionary | Do not name a variable `dict`; that shadows this built-in |
| `divmod(a, b)` | Returns `(a // b, a % b)` | Raises `ZeroDivisionError` when `b == 0` |
| `enumerate(iterable, start=0)` | Yields `(index, value)` pairs | Prefer this to manually updating an index |
| `filter(function, iterable)` | Lazily yields items for which `function` is truthy | A comprehension is often clearer |
| `float(x)` | Converts a number or numeric string to a float | May lose precision for large integers |
| `hex(integer)` | Returns a hexadecimal string | The result begins with `0x` |
| `int(x)` | Converts to an integer | A float is truncated toward zero, not floored |
| `len(container)` | Returns the number of items | The object must provide a length |
| `list(iterable)` | Creates a list from an iterable | Also useful for consuming an iterator |
| `map(function, iterable)` | Lazily applies a function to every item | A comprehension is often clearer |
| `max(iterable)`, `min(iterable)` | Returns the largest or smallest item | Support `key=`; empty iterables need `default=` or raise `ValueError` |
| `next(iterator, default)` | Returns the next item | Supplying `default` avoids `StopIteration` at exhaustion |
| `ord(character)` | Returns one character's Unicode code point | The string must contain exactly one character |
| `pow(base, exp, mod=None)` | Computes a power | With `mod`, efficiently computes modular exponentiation |
| `print(*values)` | Writes values to standard output | Returns `None` |
| `range(stop)` or `range(start, stop, step)` | Produces an integer range | `stop` is excluded; `step` cannot be zero |
| `set(iterable)` | Creates a set | Items must be hashable |
| `sorted(iterable, key=None, reverse=False)` | Returns a new sorted list | Unlike `list.sort()`, it accepts any iterable |
| `str(x)` | Returns a string representation | Calling `str()` with no argument returns `""` |
| `sum(iterable, start=0)` | Adds items from left to right | For joining strings, use `str.join()` instead |
| `type(obj)` | Returns an object's type | For normal type checks, `isinstance()` usually handles inheritance better |
| `zip(*iterables, strict=False)` | Lazily groups items from parallel iterables | Stops at the shortest input unless `strict=True` |

Avoid `eval()` for parsing input. It executes arbitrary Python code; use explicit conversions such as `int()`, `float()`, or structured parsers instead.

### Scoping in Nested Functions
Use `nonlocal <variable>` inside a nested function when rebinding a variable from the nearest enclosing function scope. Mutating an existing list, set, or dictionary does not require `nonlocal`, but assigning a new object to that variable does.

```python
def outer():
    count = 0

    def increment():
        nonlocal count
        count += 1
```

## Numbers
For positive and negative infinity, use `float("inf")` and `float("-inf")`.

- `/` performs true division and returns a float.
- `//` performs floor division, rounding down toward negative infinity.
- `%` returns the remainder associated with floor division.
- `int(x)` truncates a float toward zero. Use `math.floor(x)` when the value must always round down.

## Strings
Python has a wide range of useful built-in functions for strings. 

| Method | Description | Important behavior |
|---|---|---|
| `s.lower()`, `s.upper()` | Returns a lowercase or uppercase copy | Strings are immutable; `s` is unchanged |
| `s.count(sub[, start[, end]])` | Counts non-overlapping occurrences of `sub` | Optional bounds constrain the search |
| `s.find(sub[, start[, end]])` | Finds the first occurrence of `sub` | Returns `-1` when absent; use `sub in s` for membership only |
| `s.index(sub[, start[, end]])` | Finds the first occurrence of `sub` | Raises `ValueError` when absent |
| `s.split(sep=None, maxsplit=-1)` | Splits a string into a list | With `sep=None`, runs of whitespace are combined |
| `separator.join(strings)` | Joins strings with `separator` between them | Every item must be a string |
| `s.strip([chars])` | Removes leading and trailing whitespace or specified characters | `chars` is treated as a set of characters, not a substring |
| `s.replace(old, new[, count])` | Returns a copy with replacements | Optional `count` limits replacements |
| `s.isalnum()` | Checks whether every character is alphanumeric | Returns `False` for an empty string |
| `s.startswith(prefix)`, `s.endswith(suffix)` | Checks a prefix or suffix | Also accept a tuple of candidates |

For arbitrary characters, `Counter` is the clearest way to calculate frequencies:

```{code-block} python
---
linenos:
---
from collections import Counter

text = "abbcccddddd"
frequency = Counter(text)
print(frequency["d"])  # 5
```

If the problem guarantees lowercase English letters, a fixed array is also useful:

```{code-block} python
---
linenos:
---
text = "abbcccddddd"
frequency = [0] * 26

for character in text:
    frequency[ord(character) - ord("a")] += 1
```

Unicode code points are not limited to `0` through `127`. Only use a fixed array of size `128` when the problem explicitly guarantees ASCII input.
