# Lists, Sets, Stacks, and Queues
All data structures in this section can be iterated through using `for value in data_structure:` syntax.

## Lists
Python lists are dynamic arrays. Indexing and appending at the end are efficient, while inserting or removing near the beginning requires shifting elements.

| Method | Description | Return value and important behavior |
|---|---|---|
| `lst.append(x)` | Adds `x` to the end | Returns `None`; amortized `O(1)` |
| `lst.clear()` | Removes every item | Returns `None` |
| `lst.copy()` or `lst[:]` | Creates a shallow copy | Returns a new list |
| `lst.count(x)` | Counts items equal to `x` | Returns an integer; `O(n)` |
| `lst.extend(iterable)` | Appends every item from `iterable` | Mutates `lst` and returns `None` |
| `lst.index(x[, start[, stop]])` | Finds the first index of `x` | Raises `ValueError` when absent |
| `lst.insert(index, x)` | Inserts `x` before `index` | Returns `None`; `O(n)` in the worst case |
| `lst.pop([index])` | Removes and returns an item | Defaults to the last item; raises `IndexError` when invalid |
| `lst.remove(x)` | Removes the first item equal to `x` | Returns `None`; raises `ValueError` when absent |
| `lst.reverse()` | Reverses the list in place | Returns `None` |
| `lst.sort(key=None, reverse=False)` | Sorts the list in place | Returns `None`; use `sorted()` when a new list is needed |

You can also manipulate lists with slices:
```{code-block} python
---
linenos:
---
lst = [10, 20, 30, 40]
x = 1
start, stop, step = 0, len(lst), 2

lst[x] # value at index x in the list
lst[:] # copy of the list
lst[start:stop:step] # From the start inclusive to stop exclusive with step
```

Use `pop()` when removing by position and `remove()` when removing by value. If a value may be absent, check `if value in lst` before calling `remove()`, or use a different data structure when frequent membership checks are required.

## Sets
Sets store unique, hashable values. Membership, addition, and removal are `O(1)` on average. Set iteration order should not be relied upon.

| Operation | Description | Return value and important behavior |
|---|---|---|
| `set(iterable)` | Creates a set from an iterable | Returns a new set with duplicates removed |
| `s.add(x)` | Adds `x` | Returns `None` |
| `s.discard(x)` | Removes `x` if present | Returns `None`; does not raise when absent |
| `s.remove(x)` | Removes `x` | Returns `None`; raises `KeyError` when absent |
| `s.pop()` | Removes and returns an arbitrary element | Raises `KeyError` when the set is empty |
| `s.clear()` | Removes every element | Returns `None` |
| `x in s` | Tests membership | Returns a boolean |
| `set1 & set2` | Computes the intersection | Returns a new set |
| `set1 \| set2` | Computes the union | Returns a new set |
| `set1 - set2` | Computes the difference | Returns a new set |
| `set1 ^ set2` | Computes the symmetric difference | Returns a new set |

Prefer `discard(x)` when it is acceptable for `x` to be missing. Use `remove(x)` when absence indicates a bug and should raise an error.

## Queues
Queues follow First In, First Out (FIFO) order. Use `collections.deque`, which supports adding and removing at opposite ends in `O(1)` time.

```{code-block} python
---
linenos:
---
from collections import deque

queue = deque()
queue.append("first")
queue.append("second")

next_item = queue.popleft()  # "first"
```

`popleft()` raises `IndexError` when the deque is empty. Avoid using `list.pop(0)` for a queue because removing the first list item shifts all remaining items and takes `O(n)` time.

## Stacks
Stacks follow Last In, First Out (LIFO) order. A list is the simplest recommended implementation:

```{code-block} python
---
linenos:
---
stack = []
stack.append("first")
stack.append("second")

top = stack[-1]       # Peek: "second"
last_item = stack.pop()  # Remove: "second"
```

Both `list.append()` and `list.pop()` at the end are amortized `O(1)`. Indexing or popping an empty stack raises `IndexError`. A `deque` also supports `append()` and `pop()` in `O(1)`, but it is usually unnecessary for a stack.
