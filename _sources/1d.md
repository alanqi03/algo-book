# Classes and Additional Syntax Tips
Classes group data and behavior. Define instance attributes in `__init__` so every instance has a predictable shape.

```{code-block} python
---
linenos:
---
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"{self.name}({self.age})"

    def introduce(self):
        print(f"Hello, my name is {self.name}")


person = Person("John", 36)
person.introduce()
print(person)  # Calls person.__str__().
```

## Instance Attributes
Most Python objects allow attributes to be added at runtime, but relying on that can create inconsistent instances and hide spelling mistakes. Prefer declaring expected attributes in `__init__`:

```{code-block} python
---
linenos:
---
class TreeNode:
    def __init__(self, value, left=None, right=None, parent=None):
        self.value = value
        self.left = left
        self.right = right
        self.parent = parent
```

Classes that define `__slots__` may intentionally prevent undeclared instance attributes.

## Syntax Tips

Use `_` as a conventional throwaway name when a value is intentionally unused:

```python
for _ in range(3):
    print("repeat")

values = ("first", "unused", "last")
first, _, last = values
```
