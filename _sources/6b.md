# Tries
A trie (also called a prefix tree) is a tree-like data structure used to store and search a collection of strings efficiently.
- Each node represents a single character, and a path from the root down the tree spells out a word or prefix.
- Children are typically stored in a dictionary mapping a character to its child node.
- Especially useful for problems involving prefixes, autocomplete, and word lookups.

## Structure
Each node stores its children and a flag marking whether it is the end of a valid word.

```{code-block} python
---
linenos:
---
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_word = False
```

## Operations
A trie supports three primary operations: **insert**, **search**, and **startsWith** (prefix search).
- Each operation runs in `O(L)` time, where `L` is the length of the word or prefix (independent of how many words are stored).

```{code-block} python
---
linenos:
---
class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for c in word:
            if c not in node.children:
                node.children[c] = TrieNode()
            node = node.children[c]
        node.is_word = True

    def search(self, word):
        node = self._find(word)
        return node is not None and node.is_word

    def startsWith(self, prefix):
        return self._find(prefix) is not None

    def _find(self, s):
        node = self.root
        for c in s:
            if c not in node.children:
                return None
            node = node.children[c]
        return node
```

Walking through each method:
- `insert(word)` walks down the trie one character at a time, creating new nodes as needed, then marks the final node as the end of a word.
- `search(word)` follows the path for `word` and returns `True` only if every character exists **and** the final node is marked as a word.
- `startsWith(prefix)` follows the path for `prefix` and returns `True` if the whole prefix exists, regardless of the `is_word` flag.
- `_find(s)` is a helper that walks the path and returns the last node, or `None` if the path breaks.

Some general tips and tricks:
- Distinguishing `search` from `startsWith` comes down to whether you check the `is_word` flag.
- A trie trades memory for speed: lookups don't depend on the number of stored words.
- Tries pair naturally with backtracking/DFS when searching a board or grid for many words at once.
