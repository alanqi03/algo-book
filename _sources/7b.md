# Topological Sorting and Union Find
Both topological sorting and union find are algorithms/strategies for solving some graph problems. 

## Topological Sorting
Topological Sorting is the process of sorting the vertices in a graph such that given vertices u and v, to reach vertex v, we must have reached vertex u. Therefore, u has to appear before v in the ordering given by topological sorting. 
- This will only work with DAG (Directed, Acyclic Graph)
- Can detect a cycle in a directed graph if the algorithm doesn't order ALL nodes in the graph. 

Here is the code for topological sort.
- Note: indegree refers to the number of edges pointing into some node. 
```{code-block} python
---
linenos:
---
def topo_sort(edges):
    node_indegree = defaultdict(int)
    neighbors = defaultdict(list)
    q = deque()
    for x, y in edges:
        node_indegree[y] += 1
        neighbors[x].append(y)
    for node, indegree in node_indegree.items():
        if indegree == 0:
            q.append(node)
    ordering = []
    while q:
        node = q.popleft()
        ordering.append(node)
        for nei in neighbors[node]:
            node_indegree[nei] -= 1
            if node_indegree[nei] == 0:
                q.append(node)
    return ordering
```
The code accomplishes the following steps in order:
- Store the indegree and the neighbors of each node
- Append all nodes with indegree 0 to the queue
- While the q exists:
    - Pop node from the queue, and decrement the indegree of its neighbors
    - If the indegree becomes 0, then append to the queue

### Longest Path in a DAG: Topological Sort + DP

Finding a longest path is difficult in a general graph because the graph may contain cycles. In a DAG, however, topological sorting processes each node only after all of its incoming dependencies have been processed. This lets us combine Kahn's algorithm with dynamic programming.

Let `dp[v]` be the maximum number of edges in any path ending at node `v`. Every node starts with a path length of `0`. When processing an edge from `u` to `v`, update:

```text
dp[v] = max(dp[v], dp[u] + 1)
```

The longest path in the entire DAG is the largest value in `dp`:

```{code-block} python
---
linenos:
---
from collections import deque


def longest_path_length(num_nodes, edges):
    adj = [[] for _ in range(num_nodes)]
    indegree = [0] * num_nodes

    for u, v in edges:
        adj[u].append(v)
        indegree[v] += 1

    queue = deque(node for node in range(num_nodes) if indegree[node] == 0)
    dp = [0] * num_nodes
    processed = 0

    while queue:
        u = queue.popleft()
        processed += 1

        for v in adj[u]:
            dp[v] = max(dp[v], dp[u] + 1)

            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)

    if processed != num_nodes:
        raise ValueError("The graph must be a DAG")

    return max(dp, default=0)


edges = [
    (0, 1),
    (0, 2),
    (1, 2),
    (1, 3),
    (2, 3),
    (2, 4),
    (3, 5),
    (4, 5),
]

print(longest_path_length(6, edges))  # 4
```

The nodes are processed in topological order as they are removed from the queue, so a separate topological ordering does not need to be stored. If the graph contains a cycle, some nodes never reach an indegree of `0`; the `processed` check detects this.

#### Reconstructing the Longest Path

Finding the length does not require storing the actual path. If the path is also needed, keep track of the parent that produced each node's best `dp` value:

```{code-block} python
---
linenos:
---
from collections import deque


def longest_path(num_nodes, edges):
    adj = [[] for _ in range(num_nodes)]
    indegree = [0] * num_nodes

    for u, v in edges:
        adj[u].append(v)
        indegree[v] += 1

    queue = deque(node for node in range(num_nodes) if indegree[node] == 0)
    dp = [0] * num_nodes
    parent = [-1] * num_nodes
    processed = 0

    while queue:
        u = queue.popleft()
        processed += 1

        for v in adj[u]:
            if dp[u] + 1 > dp[v]:
                dp[v] = dp[u] + 1
                parent[v] = u

            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)

    if processed != num_nodes:
        raise ValueError("The graph must be a DAG")

    if num_nodes == 0:
        return []

    end = max(range(num_nodes), key=lambda node: dp[node])
    path = []

    while end != -1:
        path.append(end)
        end = parent[end]

    return path[::-1]


print(longest_path(6, edges))  # [0, 1, 2, 3, 5]
```

When multiple longest paths exist, this returns one of them.

Both versions take `O(V + E)` time and use `O(V + E)` space.

## Union Find
A union find is a data structure that keeps track of elements (nodes) which are split into one or more disjoint sets (connected components)
It has two primary operations: **find** and **union**:
- **find(x)** returns the root (representative) of the set containing `x` and compresses the path from `x` to that root.
- **union(x, y)** merges the two sets by attaching the root of the smaller component to the root of the larger component.

Using **path compression** and **union by size** together gives `O(α(N))` amortized time per operation, where `α` is the inverse Ackermann function and grows so slowly that the operations are effectively constant time.

Here is the code for the Union Find (DSU) data structure:
```{code-block} python
---
linenos:
---
class DSU:
    def __init__(self, n):
        self.par = list(range(n))
        self.size = [1] * n

    def find(self, x):
        if self.par[x] != x:
            self.par[x] = self.find(self.par[x])
        return self.par[x]

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False
        if self.size[rx] < self.size[ry]:
            rx, ry = ry, rx
        self.par[ry] = rx  # Attach the root of the smaller component.
        self.size[rx] += self.size[ry]
        return True
```
The two arrays track parents and component sizes.

- `par[x]` points to the next node toward the root. Initially every node is its own root.
- `size[root]` counts the nodes in the component. Only current roots hold up-to-date sizes.
- `find(x)` performs path compression by making every node on the search path point directly to the root.
- `union(x, y)` attaches the smaller component's root to the larger component's root and adds their sizes. If the sizes are equal, either root can become the parent.
- `union` returns `False` when `x` and `y` are already connected. This is useful for detecting a redundant edge or cycle.

Union Find is useful in many different applications:
- Finding which edge(s) create cycles
- Connected Components
- Counting nodes in each component. Read `dsu.size[dsu.find(x)]` for the size of the component containing `x`, or read `dsu.size[root]` for each current root to get one count per component.
- Kruskal’s Minimum Spanning Tree algorithm
- Tree Validation
