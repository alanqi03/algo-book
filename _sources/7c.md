# Minimum Spanning Trees

A **minimum spanning tree (MST)** connects every vertex in a weighted, undirected graph with the smallest possible total edge weight.

A spanning tree:

- Includes every vertex
- Has no cycles
- Has exactly `V - 1` edges

An MST exists only if the graph is connected. It may not be unique when multiple edges have the same weight.

The two common greedy algorithms are:

| Algorithm | Main idea | Typical input | Time |
|---|---|---|---|
| Prim's with a heap | Grow one tree using its cheapest outgoing edge | Sparse adjacency list | `O(E log V)` |
| Prim's with a linear scan | Grow one tree using its cheapest outgoing edge | Dense or implicit graph | `O(V²)` |
| Kruskal's | Add the cheapest edge that does not create a cycle | Edge list | `O(E log E)` |

## Prim's Algorithm

Prim's algorithm starts at any vertex and grows one connected tree by repeatedly adding its cheapest outgoing edge.

### Heap Implementation

A min-heap efficiently stores candidate edges that connect the current tree to another vertex.

1. Push a zero-cost edge to any starting vertex.
2. Pop the cheapest edge.
3. If its destination is already in the MST, skip it.
4. Otherwise, add its cost and push its outgoing edges.
5. Continue until all vertices are included.

```{code-block} python
---
linenos:
---
import heapq

def prim(n, graph):
    """graph[u] contains (weight, v) pairs; vertices are 0 through n - 1."""
    if n == 0:
        return 0

    total_cost = 0
    vertices_used = 0
    in_mst = [False] * n
    heap = [(0, 0)]  # (edge weight, destination)

    while heap and vertices_used < n:
        weight, u = heapq.heappop(heap)

        if in_mst[u]:
            continue

        in_mst[u] = True
        total_cost += weight
        vertices_used += 1

        for next_weight, v in graph[u]:
            if not in_mst[v]:
                heapq.heappush(heap, (next_weight, v))

    return total_cost if vertices_used == n else -1
```

Returning `-1` means the graph is disconnected, so one spanning tree cannot reach every vertex.

### Linear-Scan Implementation for Points

When the graph is dense or can be generated from the input, we do not need to store every edge. For a set of points, every pair is connected and the edge weight is their Manhattan distance. Keep:

- `in_mst[v]`: whether point `v` has already been added
- `min_dist[v]`: the cheapest known edge from the current MST to point `v`

Each outer-loop iteration scans for the unvisited point with the smallest `min_dist`, adds it, then computes its distance to every other unvisited point to update their best connections.

```{code-block} python
---
linenos:
---
def min_cost_connect_points(points):
    n = len(points)
    if n == 0:
        return 0

    in_mst = [False] * n
    min_dist = [float("inf")] * n
    min_dist[0] = 0
    edges_used = 0
    min_cost = 0

    while edges_used < n:
        curr_dist = float("inf")
        curr_node = -1

        # Find the closest point that is not in the MST yet.
        for node in range(n):
            if not in_mst[node] and min_dist[node] < curr_dist:
                curr_dist = min_dist[node]
                curr_node = node

        in_mst[curr_node] = True
        min_cost += curr_dist
        edges_used += 1

        # Update the cheapest known connection for every remaining point.
        for next_node in range(n):
            if in_mst[next_node]:
                continue

            weight = (
                abs(points[curr_node][0] - points[next_node][0])
                + abs(points[curr_node][1] - points[next_node][1])
            )
            if weight < min_dist[next_node]:
                min_dist[next_node] = weight

    return min_cost
```

The implementation is correct because the point graph is complete: every unvisited point always has a finite connection from the MST. At each iteration, Prim's cut property says the cheapest edge crossing from the current MST to an unvisited point can safely be added. The first point contributes `0`, representing the starting vertex rather than an edge.

The outer loop runs `V` times, and both scans examine at most `V` points, so the time is `O(V²)`. The arrays use `O(V)` auxiliary space. For a general graph that may be disconnected, detect when no finite `curr_node` is found and report that no spanning tree exists.

## Kruskal's Algorithm

Kruskal's algorithm considers all edges from cheapest to most expensive. It uses a Disjoint Set Union (DSU) to check whether two vertices are already connected.

1. Sort all edges by weight.
2. Add an edge if it connects two different components.
3. Stop after choosing `V - 1` edges.

```{code-block} python
---
linenos:
---
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        if x != self.parent[x]:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        root_a = self.find(a)
        root_b = self.find(b)

        if root_a == root_b:
            return False

        if self.size[root_a] < self.size[root_b]:
            root_a, root_b = root_b, root_a

        self.parent[root_b] = root_a
        self.size[root_a] += self.size[root_b]
        return True


def kruskal(n, edges):
    """edges contains (weight, u, v) tuples; vertices are 0 through n - 1."""
    if n <= 1:
        return 0

    dsu = DSU(n)
    total_cost = 0
    edges_used = 0

    for weight, u, v in sorted(edges):
        if dsu.union(u, v):
            total_cost += weight
            edges_used += 1

            if edges_used == n - 1:
                return total_cost

    return -1
```

DSU's `find` operation identifies a vertex's component. If two vertices have the same root, adding their edge would create a cycle, so Kruskal skips it.
