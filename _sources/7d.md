# Shortest Path Algorithms

Shortest-path algorithms find the minimum total edge weight from a source node to other nodes. The best algorithm depends mainly on the edge weights.

| Edge weights | Algorithm | Time | Auxiliary space |
|---|---|---|---|
| All edges have the same weight | BFS | `O(V + E)` | `O(V)` |
| All weights are non-negative | Dijkstra | `O(V + E log E)` | `O(V + E)` |
| Negative weights may exist | Bellman–Ford | `O(VE)` | `O(V)` |

Both directed and undirected graphs are supported. However, a negative edge in an undirected graph immediately creates a negative cycle: traverse the edge in both directions.

The space bounds below are **auxiliary space** and do not include the input graph.

## Relaxing an Edge

Both Dijkstra and Bellman–Ford repeatedly **relax** edges. For an edge `u -> v` with weight `w`, ask whether reaching `v` through `u` is cheaper:

```python
if dist[u] + w < dist[v]:
    dist[v] = dist[u] + w
```

Initially, the source has distance `0` and every other node has distance infinity.

## Breadth-First Search (BFS)

When every edge has the same weight, BFS finds a shortest path without a heap. A FIFO queue visits nodes in order of increasing distance from the source. Mark a node as visited when you **enqueue** it so it is not added again through another edge.

```{code-block} python
---
linenos:
---
from collections import deque

def bfs_shortest_path(graph, source, target):
    """graph[u] contains the neighbors of u; return a path or None."""
    queue = deque([source])
    parent = {source: None}

    while queue:
        u = queue.popleft()
        if u == target:
            path = []
            while u is not None:
                path.append(u)
                u = parent[u]
            return path[::-1]

        for v in graph[u]:
            if v not in parent:
                parent[v] = u
                queue.append(v)

    return None  # Target is unreachable.
```

The first time BFS reaches `target`, it has used the fewest edges. The returned path includes both endpoints; return `None` if no path exists. To find distances to *every* node instead, store `distance[v] = distance[u] + 1` when `v` is first enqueued and let the queue run to completion.

- **Time:** `O(V + E)` because every vertex and edge is processed at most once.
- **Auxiliary space:** `O(V)` for the queue and parent map.

### Multi-Source BFS: Walls and Gates

If the goal is the distance to the **nearest** source, enqueue *all* sources at distance `0` before starting BFS. In Walls and Gates, each cell is a wall (`-1`), a gate (`0`), or an empty room (`INF = 2**31 - 1`). Walking to an adjacent cell costs one step. Fill each empty room with its shortest distance to any gate, leaving unreachable rooms as `INF`.

```{code-block} python
---
linenos:
---
from collections import deque

def walls_and_gates(rooms):
    """Fill rooms in place with distance to the nearest gate."""
    if not rooms or not rooms[0]:
        return

    INF = 2**31 - 1
    rows, cols = len(rooms), len(rooms[0])
    queue = deque()

    for row in range(rows):
        for col in range(cols):
            if rooms[row][col] == 0:
                queue.append((row, col))

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
    while queue:
        row, col = queue.popleft()
        for dr, dc in directions:
            nr, nc = row + dr, col + dc
            if 0 <= nr < rows and 0 <= nc < cols and rooms[nr][nc] == INF:
                rooms[nr][nc] = rooms[row][col] + 1
                queue.append((nr, nc))
```

For example:

```{code-block} python
---
linenos:
---
INF = 2**31 - 1
rooms = [
    [INF, -1, 0, INF],
    [INF, INF, INF, -1],
    [INF, -1, INF, -1],
    [0, -1, INF, INF],
]
walls_and_gates(rooms)
# rooms is now:
# [[3, -1, 0, 1],
#  [2, 2, 1, -1],
#  [1, -1, 2, -1],
#  [0, -1, 3, 4]]
```

Each empty room is assigned a distance and enqueued **once**, when the first (and therefore closest) gate reaches it. Using the grid itself to mark visited rooms avoids a separate set.

- **Time:** `O(RC)` because each cell is processed at most once.
- **Auxiliary space:** `O(RC)` in the worst case for the queue.

## Dijkstra's Algorithm

Dijkstra's algorithm works only when every edge weight is non-negative. It greedily processes the closest known node using a min-heap.

1. Set `dist[source] = 0` and push `(0, source)` onto the heap.
2. Pop the node with the smallest distance.
3. Relax each outgoing edge and push any improved distance.
4. Repeat until the heap is empty.

```{code-block} python
---
linenos:
---
import heapq

def dijkstra(n, graph, source):
    """graph[u] contains (v, weight) pairs; nodes are 0 through n - 1."""
    dist = [float("inf")] * n
    dist[source] = 0
    heap = [(0, source)]

    while heap:
        curr_dist, u = heapq.heappop(heap)

        # A shorter route to u was added after this entry.
        if curr_dist != dist[u]:
            continue

        for v, weight in graph[u]:
            new_dist = curr_dist + weight
            if new_dist < dist[v]:
                dist[v] = new_dist
                heapq.heappush(heap, (new_dist, v))

    return dist
```

- A node is unreachable when its distance remains infinity.
- BFS is the simpler equivalent when all edges have the same weight.
- To reconstruct paths, store `parent[v] = u` whenever `dist[v]` improves.

With this implementation, the heap may contain stale entries. There are at most `E` successful relaxations and therefore `O(E)` heap pushes and pops, each taking `O(log E)` time.

- **Time:** `O(V + E log E)`.
- **Auxiliary space:** `O(V + E)` for the distance array and heap.

### State-Space Dijkstra

Some shortest-path problems cannot be described by the current node alone. Future moves may also depend on a limited resource or another condition, such as:

- how many discounts or free edges have been used;
- how much fuel remains;
- which keys have been collected;
- how many obstacles have been removed.

Treat each combination as a separate node in an **expanded state graph**. For example, `(u, 0)` and `(u, 1)` are different states when the second value counts free edges already used. The distance table and heap must contain the full state, not just `u`.

The following algorithm finds the cheapest path when up to `max_free_edges` edges may be traversed for free:

```{code-block} python
---
linenos:
---
import heapq


def shortest_path_with_free_edges(
    n, graph, source, target, max_free_edges
):
    """graph[u] contains (v, weight) pairs with non-negative weights."""
    dist = [
        [float("inf")] * (max_free_edges + 1)
        for _ in range(n)
    ]
    dist[source][0] = 0
    heap = [(0, source, 0)]  # (cost, node, free edges used)

    while heap:
        cost, u, used = heapq.heappop(heap)

        if cost != dist[u][used]:
            continue
        if u == target:
            return cost

        for v, weight in graph[u]:
            # Option 1: pay the edge's normal cost.
            paid_cost = cost + weight
            if paid_cost < dist[v][used]:
                dist[v][used] = paid_cost
                heapq.heappush(heap, (paid_cost, v, used))

            # Option 2: consume one free traversal.
            if used < max_free_edges and cost < dist[v][used + 1]:
                dist[v][used + 1] = cost
                heapq.heappush(heap, (cost, v, used + 1))

    return -1  # Target is unreachable in every state.
```

Example:

```{code-block} python
graph = [
    [(1, 5), (2, 20)],
    [(3, 5)],
    [(3, 1)],
    [],
]

shortest_path_with_free_edges(4, graph, 0, 3, 1)
# Returns 1: traverse edge 0 -> 2 for free, then pay 1 for 2 -> 3.
```

A single `dist[u]` would be incorrect: a more expensive arrival at `u` with a free traversal remaining may lead to a cheaper final route than a less expensive arrival that has already used it.

The algorithm may return as soon as a target state is popped because the heap orders **all states** by cost. As with ordinary Dijkstra, every state transition must have a non-negative cost.

With `K` free traversals, the expanded graph has `V(K + 1)` states and `O(E(K + 1))` transitions.

- **Time:** `O(V(K + 1) + E(K + 1) log(E(K + 1)))`.
- **Auxiliary space:** `O(V(K + 1) + E(K + 1))` for the distance table and heap.

## Bellman–Ford Algorithm

Bellman–Ford is slower than Dijkstra, but it supports negative edge weights and detects reachable negative cycles.

Why `V - 1` passes? Any shortest **simple** path visits at most `V` vertices, so it uses at most `V - 1` edges. Each full pass can extend known shortest paths by one edge.

1. Relax every edge `V - 1` times.
2. Stop early if a complete pass makes no changes.
3. Make one extra pass. If any distance improves, a negative cycle is reachable from the source.

```{code-block} python
---
linenos:
---
def bellman_ford(n, edges, source):
    """edges contains (u, v, weight) tuples; nodes are 0 through n - 1."""
    dist = [float("inf")] * n
    dist[source] = 0

    for _ in range(n - 1):
        changed = False

        for u, v, weight in edges:
            if dist[u] != float("inf") and dist[u] + weight < dist[v]:
                dist[v] = dist[u] + weight
                changed = True

        if not changed:
            break

    # Only detects negative cycles reachable from source.
    for u, v, weight in edges:
        if dist[u] != float("inf") and dist[u] + weight < dist[v]:
            return dist, True

    return dist, False
```

A **negative cycle** has a total weight below zero. Repeating it makes a path cheaper forever, so no finite shortest path exists for nodes reachable through that cycle.

- **Time:** `O(VE)` in the worst case because up to `V - 1` passes scan all `E` edges, followed by one cycle-detection pass.
- **Auxiliary space:** `O(V)` for the distance array.

### Limiting the Number of Edges

Some problems ask for the cheapest path using at most `k` edges. Copy `dist` before each pass so one pass cannot use multiple new edges:

```python
for _ in range(k):
    next_dist = dist[:]
    for u, v, weight in edges:
        if dist[u] != float("inf"):
            next_dist[v] = min(next_dist[v], dist[u] + weight)
    dist = next_dist
```

For example, “at most `k` stops” allows at most `k + 1` edges, so run `k + 1` passes.

- **Time:** `O(k(V + E))` for `k` passes; each pass copies the distance array and scans every edge.
- **Auxiliary space:** `O(V)` for `dist` and `next_dist`.
