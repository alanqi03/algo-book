# Knapsack DP
Several DP problems ask you to solve the following problem (or similar variations):

Given N items where each item has some weight and profit associated with it, and a bag with capacity W (the bag can hold at most W weight), put items into the bag such that the sum of profits is the maximum possible.

The state is `dp(i, c)` = the best profit achievable considering items from index `i` onward with remaining capacity `c`. There are two major variants depending on how many times each item can be used.

Top-down (recursion with memoization) is the most intuitive way to write knapsack, since it mirrors the decision directly: for item `i` with remaining capacity `c`, do I take it or skip it? The only difference between the two variants is what happens *after* you take an item.

## 0/1 Knapsack
Each item can be taken **at most once**. For each item, you either skip it (move to the next item) or take it (move to the next item with reduced capacity).

### Top-down
```{code-block} python
---
linenos:
---
def knapsack_01(weights, profits, W):
    @lru_cache(None)
    def dp(i, c):
        if i == len(weights):
            return 0                    # no items left
        skip = dp(i + 1, c)
        take = 0
        if weights[i] <= c:
            take = profits[i] + dp(i + 1, c - weights[i])
        return max(skip, take)
    return dp(0, W)
```
- `dp(i, c)` is the max profit considering items from index `i` onward with capacity `c`.
- **skip**: move to item `i + 1` with the same capacity.
- **take** (only if it fits): earn its profit and move to item `i + 1` with less capacity.
- Because both branches advance to `i + 1`, each item is considered exactly once.

### Bottom-up
The same recurrence, filled iteratively into a 1D array where `dp[c]` is the best profit for capacity `c`:
```{code-block} python
---
linenos:
---
def knapsack_01(weights, profits, W):
    dp = [0] * (W + 1)
    for i in range(len(weights)):
        # iterate capacity DOWNWARD so each item is used at most once
        for c in range(W, weights[i] - 1, -1):
            dp[c] = max(dp[c], dp[c - weights[i]] + profits[i])
    return dp[W]
```
- The capacity loop goes **downward** so that `dp[c - weight]` still refers to a state from *before* the current item was added — this enforces "use each item at most once".
- Uses `O(W)` space instead of the recursion's `O(N*W)` memo.

## Unbounded Knapsack
Each item can be taken **any number of times**. The only change from 0/1 is that when you take an item, it remains available.

### Top-down
```{code-block} python
---
linenos:
---
def knapsack_unbounded(weights, profits, W):
    @lru_cache(None)
    def dp(i, c):
        if i == len(weights):
            return 0
        skip = dp(i + 1, c)
        take = 0
        if weights[i] <= c:
            take = profits[i] + dp(i, c - weights[i])   # stay on i to reuse
        return max(skip, take)
    return dp(0, W)
```
- The single difference from 0/1: the **take** branch recurses on `dp(i, ...)` instead of `dp(i + 1, ...)`.
- Staying on index `i` lets the same item be chosen again, allowing unlimited reuse.

### Bottom-up
```{code-block} python
---
linenos:
---
def knapsack_unbounded(weights, profits, W):
    dp = [0] * (W + 1)
    for i in range(len(weights)):
        # iterate capacity UPWARD so an item can be reused
        for c in range(weights[i], W + 1):
            dp[c] = max(dp[c], dp[c - weights[i]] + profits[i])
    return dp[W]
```
- The capacity loop goes **upward**, so `dp[c - weight]` may already include the current item — allowing it to be picked multiple times.

## Tips and tricks
- Top-down mirrors the decision most directly; the key difference between variants is the recursive call after taking an item: **`i + 1` = 0/1** (each item once), **`i` = unbounded** (unlimited reuse).
- In bottom-up, that same distinction becomes the inner loop direction: **downward = 0/1**, **upward = unbounded**.
- Many problems are knapsack in disguise: a "subset that sums to a target" is 0/1 with weights = values and capacity = target; "coin change" (min coins / count ways) is unbounded knapsack.
