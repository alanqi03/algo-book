# 1D DP
1D DP problems use a single dimension (one variable) to describe each subproblem, typically an index `i` into an array or a step count. The state is stored in a 1D array `dp` where `dp[i]` is the answer for the subproblem ending at (or using) index `i`.

## When to use
1. The problem is over a linear sequence (array or string) and each state depends only on a constant number of previous states.
2. You're asked for an optimum (max/min) or a count of ways, and the decision at index `i` depends on earlier indices like `i-1` or `i-2`.

## Algorithm
Define `dp[i]` as the answer for the prefix ending at index `i`, then write a recurrence relating it to earlier entries. The classic example is climbing stairs, where you can take 1 or 2 steps:
```{code-block} python
---
linenos:
---
def climb_stairs(n):
    dp = [0] * (n + 1)
    dp[0] = dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]
```
- `dp[i]` is the number of ways to reach step `i`.
- The recurrence `dp[i] = dp[i-1] + dp[i-2]` says you arrive from either one or two steps below.
- Base cases: there is one way to be at step 0 (do nothing) and one way to reach step 1.

Sometimes `dp[i]` depends on *all* earlier indices, not just the last one or two. Longest Increasing Subsequence (LIS) is the classic example — `dp[i]` is the length of the longest increasing subsequence *ending at* index `i`:
```{code-block} python
---
linenos:
---
def length_of_lis(nums):
    dp = [1] * len(nums)                # each element alone is a subsequence of length 1
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:       # can extend the subsequence ending at j
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```
- `dp[i]` is the length of the longest increasing subsequence that ends at index `i`.
- For each `i`, we look back at every earlier `j` and extend if `nums[j] < nums[i]`.
- The answer is the best value over all ending positions, so we take `max(dp)` rather than `dp[-1]`.
- This scan-all-previous pattern makes it `O(n^2)` instead of the `O(n)` of climbing stairs.

## Tips and tricks
- If `dp[i]` only depends on the last few entries, you can drop the array and keep a couple of variables, reducing space from `O(n)` to `O(1)`.
- Choosing what `dp[i]` means (ending *at* `i` vs. using the first `i` elements) is the most important decision; the recurrence follows from it.
